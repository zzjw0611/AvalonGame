# 0.2.0 修改与验收记录

核对日期：2026-09-24。被测代码提交：`6d32e55583343a9665609035facb309043ec338e`。

## 本次要求已实现

- 手机默认连接 `https://42.193.181.239`（443），首页无服务器输入或切换入口。仅输入昵称及服务器要求的内测邀请码；旧其他主机的凭证不会转发。
- 「配置圆桌」改为「创建房间」。选择总人数、真人席位数和角色配置，自动显示剩余 AI 数量；真人数包含参赛房主。支持远程房间号加入和房主仅观战。
- 移除可选规则机器人、后端 `bot` 座位与生产代码的脚本决策函数，只可创建 `human` / `llm`。旧客户端提交 `bot` 返回 422。测试中保留的模拟模型仅用于测试，不是生产玩家或兜底。
- 未配置模型时明确提示「AI 暂不可用」，可手动选择全真人，绝不自动用脚本顶替。
- 模型失败、超时或预算不足暂停整个房间，由房主重试。保留秘密票、身份、阶段和预算；不自动代投或发言。暂停提示不透露失败座位或任务牌；过期的模型响应不能在恢复后提交。
- 旧的含已移除座位类型的未结束房间只读归档，不删除、不自动转换为收费 AI。已结束房间保留复盘。
