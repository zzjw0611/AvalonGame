# 规则集：经典顺序任务 + 显式移动端房间协议

全员秘密选择赞成/反对，收齐同时公开；严格多数通过，平票否决。第五次连续否决直接邪恶胜，不自动通过、不算仅一项任务失败。通过队伍只由队员秘密提交任务牌，好人仅成功，邪恶成功/失败皆可。仅公开失败牌总数，不公开归属。三次失败直接邪恶胜；三次成功后进入刺杀，未结束前不亮角色。

初始梅林看见除莫德雷德外的邪恶，含奥伯伦；非奥伯伦邪恶互认排除奥伯伦，只给阵营不授予队友精确角色；奥伯伦无互认；派西维尔得到按座位排序的梅林/莫甘娜候选集合；忠臣无额外视野。初始队长使用系统随机数，角色随机分配，每席一角色。

此规则集固定一梅林一刺客，可选四种特殊角色，剩余补普通角色。固定梅林/刺客是本项目范围，不宣称所有官方可选版本都强制如此。五人派西维尔需搭配莫甘娜或莫德雷德。角色阵营数量不可超过表中名额。

## APP 房间协议（非官方硬规则）

- 队长先锁定提案，再从队长下一席开始逐席公开讨论，队长最后，每席一次发言（最多240字符）或跳过，然后全员密票。
- 第三个任务成功后全员再各有一次公开陈述，随后仅刺客一次指认。这里采用全员最终公开陈述，而非独立邪恶私聊频道；不自动公布刺客/奥伯伦身份。
- 可设发言15–180秒，其他行动15–300秒（手机默认90秒）。超时：跳过发言、反对提案、提交成功；队长/刺客选合法菜单第一项。此约定可能影响公平性与胜率，在开局前展示。
- 刺杀菜单为刺客之外全部座位，不用后台真实阵营筛选；任何非梅林目标都判未命中，不允许错误提示后重选。
- 模型错误、超时或预算不足可改用只读自身视角的规则兜底；这不是强模型表现，结束后显示统计。真人超时同样应用公开约定。
- 不实现湖中仙女、乱序 Targeting、兰斯洛特、其他 Big Box 扩展、无梅林玩法、11人以上变体。不能通过自定义人数参数绕过。

允许在发言中诈身份、说谎和推测；“我自称梅林”不是后台角色认证。发言不能改写系统规则。禁止通过接口查看其他玩家的私密状态不是靠 Prompt 自觉，而是服务端投影和权限检查。
